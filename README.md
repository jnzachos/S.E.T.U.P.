# S.E.T.U.P.
Systemic Exploitation Toolkit Ultimate Provisioner

An automated setup script for a Debian-based Linux hacking environment.

## Included Tools 
The script automates the installation and setup of hacking tools, including:
* **Text Editors** 
* **Exploitation tools** 
* **Networking tools**
* **Reconnaissance tools**
* **Reverse engineering and binary analysis tools**

<br>

# How to use

1. **Clone the repository to your machine**

```bash
git clone https://github.com/jnzachos/S.E.T.U.P..git
```

2. **Navigate into the script directory**
```bash
cd S.E.T.U.P./hacking-setup
```

3. **Run the script**
```bash
./setup.sh
```

4. **Clean up (Optional):**

    Once the script finishes, you can safely remove the cloned repository from your system:

```bash
   cd ../.. && rm -rf S.E.T.U.P.
```
